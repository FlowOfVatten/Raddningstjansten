# need2where (MVP)

Behovsbaserad sokprototyp: "Vad vill jag ha?" -> "Var kan jag hitta det nara mig?"

## Funktioner

- Geolocation via webblasaren
- Landsregel-per-behov (start: Sverige, Finland, USA + fallback)
- POI-sokning via OpenStreetMap Overpass
- Karta med Leaflet
- Forslag med avstand och lank till vagbeskrivning

## Kor lokalt

1. Oppna `need2where/index.html` i browser, eller via Live Server i VS Code.
2. Klicka `Hamta min position`.
3. Valj behov och klicka `Hitta narmaste`.

## Viktigt

- Resultat visar sannolika saljstallen baserat pa OSM-taggar.
- Appen garanterar inte lagerstatus eller exakt juridisk tolkning i realtid.
