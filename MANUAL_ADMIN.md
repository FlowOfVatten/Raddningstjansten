# Anvandarmanual - Admin/Arrangor

## 1. Syfte
Denna manual visar hur du som admin skapar och hanterar:
- vanliga ovningar
- rokovningar
- personalregister

## 2. Snabbstart
1. Oppna `admin.html`.
2. Logga in med adminlosenord.
3. Valj om du vill jobba med `Vanliga event` eller `Rokovning`.

## 3. Skapa vanlig ovning
1. Fyll i grunddata:
- Namn pa ovning
- Min och max antal
- Start/sluttid (standard)
- Arrangorens namn (och e-post om du vill ha notiser)
2. Markera ett eller flera datum i kalendern.
3. Fyll i plats och tid for varje valt datum.
4. Klicka `Spara event`.

## 4. Skapa rokovning
1. Gå till fliken `Rokovning`.
2. Valj:
- Agarstation
- Typ (`Varm` eller `Kall`)
3. Valj datum i kalendern, eller aktivera `Veckolage` och valj veckor.
4. For varje datum/vecka: valj station som ska ova.
5. Klicka `Skapa rokovningar`.

## 5. Hantera sparade ovningar
1. Vanliga ovningar:
- Valj event i listan `Sparade event`
- `Redigera` for att andra
- `Ta bort` for att radera
2. Rokovningar:
- Se listan under rokovningsdelen
- `Ta bort` for att radera en enskild rad

## 6. Personalregister
1. Skriv namn.
2. Valj station.
3. Klicka `Lagg till person`.
4. Anvand `Visa personal for station` for att filtrera.
5. Klicka `Ta bort` pa en personrad vid behov.

## 7. Rensa data
Det finns tva separata knappar:
- `Rensa vanliga ovningar`
- `Rensa rokovningar`

Bada har dubbel bekraftelse for att minska risken for fel.

## 8. Vanliga fel och losningar
- `Du behover ange namn pa ovningen.`
: Fyll i namn innan du sparar.
- `Valj minst ett datum i kalendern.`
: Markera minst en dag.
- `Alla valda datum maste ha ort, starttid och sluttid.`
: Kontrollera varje datumrad.
- `Valj agarstation.`
: Valj agarstation innan du skapar rokovning.
- `Valj vilken station som ska ova for varje datum/vecka.`
: Fyll i station pa alla rader.

## 9. Begrepp
- `Agarstation`: stationen som ansvarar for rokovningen.
- `Ovningsstation`: stationen som ska ova.
- `Varm rokovning`: kan redigeras med grupp, antal, styrkeledare.
- `Kall rokovning`: enklare kort utan redigeringsdel i publik vy.
- `Veckolage`: planering per vecka i stallet for enstaka datum.
