# Brandvatten

Mobilfokuserad kartapp for att snabbt hitta narmaste brandvattenpunkt.

## Funktioner

- Hamta telefonens position nar sidan oppnas.
- Identifiera narmaste destination automatiskt.
- Visa vagbeskrivning till vald destination via Azure Maps Routing API.
- Klicka pa valfri punkt for mer info och bild.
- Manuell knapp `Navigera hit` for alla destinationer.

## Filer

- `index.html`
- `style.css`
- `app.js`
- `config.js` (Azure Maps nyckel)

## Starta

Oppna `index.html` i webblasare eller via Live Server.

## Notering

Appen anvander exempeldata med 3 testdestinationer och generiska bilder.
